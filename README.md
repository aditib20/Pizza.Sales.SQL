# 🍕 Pizza Sales Analysis — SQL Project

## 📌 Project Overview

This project analyzes pizza sales data using SQL to uncover insights related to sales performance, customer ordering patterns, pizza popularity, revenue contribution, and product performance.

The analysis was performed using **MySQL** and **MySQL Workbench**, with SQL queries used to answer a series of business-focused questions.

## 🛠️ Tools Used

- MySQL
- MySQL Workbench

## 📚 SQL Concepts Used

- SELECT statements
- Aggregate Functions
- GROUP BY
- ORDER BY
- WHERE
- HAVING
- JOINs
- CASE Statements
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Date and Time Functions

- ## 🔎 Business Questions

The project answers the following business questions:

1. What is the total number of orders placed?
2. What is the total revenue generated from pizza sales?
3. What is the highest-priced pizza?
4. What is the most commonly ordered pizza size?
5. What are the top 5 most ordered pizza types?
6. What is the total quantity of pizzas ordered for each pizza category?
7. How are orders distributed throughout the day?
8. What is the average number of pizzas ordered per day?
9. What are the top 3 most ordered pizza types based on revenue?
10. What is the percentage contribution of each pizza type to total revenue?
11. What is the cumulative revenue generated over time?
12. What are the top 3 most ordered pizza types based on revenue for each pizza category?

## 💡 Key Insights

The analysis helped identify important patterns in pizza sales, including:

- Identified the overall sales volume and total revenue generated.
- Identified the most frequently ordered pizza size.
- Identified the top-performing pizza types based on order quantity.
- Compared sales performance across different pizza categories.
- Analyzed revenue contribution by individual pizza types.
- Analyzed revenue trends over time.
- Identified the top 3 pizza types by revenue within each pizza category.
- Analyzed ordering patterns by hour of the day.


## 🎯 Conclusion

This project demonstrates the use of SQL to analyze pizza sales data and extract meaningful business insights. The analysis covers sales performance, product popularity, revenue trends, customer ordering patterns, and category-level performance.

The project helped strengthen practical skills in SQL querying, data aggregation, joins, subqueries, CTEs, and window functions while solving real-world business questions.
